Frequently Asked Questions

Order ဘယ်လိုတင်ရမလဲ?

Service ကိုရွေး၊ လိုအပ်တဲ့ Link နဲ့ Quantity ဖြည့်ပြီး Telegram ကနေ ပေးပို့ပါ။ Admin အတည်ပြုချက်ရမှ Order ကို စတင်ပါ။

ဈေးနှုန်းတွေ ဘယ်လိုသိနိုင်မလဲ?

ဝန်ဆောင်မှုအလိုက် ဈေးနှုန်းနဲ့ ရရှိနိုင်မှုက ကွာခြားနိုင်ပါတယ်။ Order မတင်ခင် Admin ထံမှ လက်ရှိဈေးနှုန်းကို အတည်ပြုပါ။

Order တင်ပြီး ဘယ်လောက်ကြာမလဲ?

ဝန်ဆောင်မှုအမျိုးအစားနဲ့ Provider အလိုက် အချိန်ကွာခြားနိုင်ပါတယ်။ ခန့်မှန်းအချိန်ကို Order မတင်မီ မေးမြန်းပါ။

အကူအညီလိုရင် ဘယ်လိုဆက်သွယ်မလဲ?

အောက်ပါ Telegram Contact ကို အသုံးပြုပြီး မေးမြန်းနိုင်ပါတယ်။
